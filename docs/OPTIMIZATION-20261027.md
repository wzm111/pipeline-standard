# 2026-10-27 pipeline 自优化：角色模型交接

档位：standard，单批次。当前agent直接实现，持久tester补查边界；没有为计划、摘要或提交增加角色。

## 改进

- resolve-models.py增加`--role <角色> --compact`，仅返回当前角色配置及来源，不重复转发全部角色。
- 增加`--host-evidence <本run能力JSON>`，通过既有双端适配器生成只读launch_plan；保留权限、强度、fork约束和显式回退校验，减少手工拼装参数。
- 原有完整配置查询、--read和临时覆盖接口保持兼容；模式冲突、坏输入和配置损坏明确失败，不隐藏错误。
- Codex规则及模型说明接入精简查询。宿主能力由智能体依据当前实际工具准备，用户仍以自然语言操作，无需填写额外文件。

参数预览不创建角色、不修改配置、不验证实际模型身份；预检verified仍为false。Claude预览中effort=null表示删除旧字段，不能原样写入frontmatter。

## 验证

新增7项真实CLI行为测试；全套77项行为测试、安装冒烟、Shell语法、差异检查与skill校验通过。独立tester复用已有结果并补验两端异常宿主输入、模式冲突、临时来源和文件无副作用，未发现剩余问题。

当前项目的Codex配置输出：完整查询973字节；`--role tester --compact`为140字节，减少85.6%。此为同一配置的输出字节比较，不是token计数，也不是需求耗时A/B实验；没有据此承诺总开发提速。

项目/个人模型配置未修改。实际模型启动、远端CI和真实需求A/B基准仍沿用既有待验证项，不算作本轮验收已完成。
