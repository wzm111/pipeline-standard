# v3.14.17 例行发布模型选择

- Codex 已验收的例行发布优先沿用 Sol 低或中的主会话。主会话使用 Astra 或 Sol 高及以上时，解析器在宿主能力和权限已核验的情况下，可建议由一个配置好的 Sol 发布角色接手。
- 发布仍沿用既有授权、候选、预检与回读。复杂变更与异常恢复沿用原风险和专家流程。

Codex can now select a single executor for an already approved routine release. A suitable Sol session continues directly. A heavier main session can hand off to a configured Sol releaser after host preflight. Existing release gates still apply.

本地回归覆盖执行者选择、宿主权限未知及例行发布与复杂任务的边界。本次发布在实际 Sol 中强度主会话验证了直通，独立发布角色的原生接手待试用。
