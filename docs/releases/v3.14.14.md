# v3.14.14 开工与方案返回进度门禁

- 首次正式派发前，必须登记当前任务中已发送且格式合规的开工进度。
- 高风险任务须在当前方案评审通过后，发送并登记合规的方案返回进度，才能进入实施、派发开发或通过写入预检。
- Pipeline 核验登记格式和时序，消息由主调度员发送。

Managed tasks require recorded kickoff feedback before the first dispatch. High-risk implementation requires valid feedback sent after the current solution review passed.
