# v3.14.11 项目级切流门禁

- 项目可在根目录的 `pipeline.release.json` 中声明切流守卫和依赖。在发布准备时固定声明与守卫指纹，切流前核对候选产物与守卫依赖的 SHA-256。
- 已配置守卫的项目须通过受管发布入口执行切流。普通检查和宿主观察入口不能代替该步骤。
- 本地通过 789 项 Python 测试、Codex 冒烟和 Shell 语法检查。

Projects can opt in to an activation guard through `pipeline.release.json`. Pipeline binds its inputs and the release candidate to the managed activation step.
