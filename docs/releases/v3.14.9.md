# v3.14.9 Pipeline 进度与高风险收口门禁

- 新建受管运行和任务进入正式验证或人工等待前，须登记当前任务的有效进度消息。
- 明确分类为高风险的受管任务收口前，核对本任务的独立评审、已完成的原生派发、实际宿主身份以及模型路由证据。缺少实际反馈或路线不匹配会阻止完成。
- 工程 QA 与流程合规分开报告。工程检查通过后可保留通过结果，随后补齐流程证据。

New managed tasks require recorded progress before formal verification or a human wait. High-risk closeout checks current review, native dispatch, and model routing evidence separately from engineering QA.
