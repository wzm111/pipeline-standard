# v3.14.1 跨项目审计与评审改进

- 跨项目审计展示候选覆盖、状态文件修改时间和规则确认状态。`--summary-only` 可查看覆盖摘要。日期筛选区分命中记录和无日期诊断，并保留过期快照造成的覆盖缺口。
- 补充构建耗时排查、检查复用预检和外部工单证据交接指引。
- 架构评审可从近期反复共同修改的路径确定范围。方案原型保留可复跑步骤，临时故障须确认进入实际被测路径。

本地通过 760 项回归测试和 Codex 安装冒烟。项目日志的覆盖范围以扫描结果为准，实际提速仍需要新样本验证。

This release improves cross-project audit coverage and adds a summary-only view, with focused guidance for architecture reviews, prototype comparisons, and evidence handoffs.
