# v3.14.2 高风险任务与专家模型路由

影响投流归因或广告优化的转化埋点纳入高风险评审，支付变更继续按高风险规则处理。实现或修复可走单独的高风险开发路线，方案评审和验收由独立执行者负责。

本仓库的 Codex 配置为方案评审与实现或修复使用 GPT-6 Astra 高强度，独立验收使用 GPT-6.1 Sol 高强度。其他项目根据各自的项目配置和本机默认解析模型。登记了原生派发参数与显式推理强度时，参数缺少强度会被拒绝。宿主实际型号以宿主回报为准。

本地通过 761 项回归测试和 Codex 安装冒烟。

This release adds configurable high-risk implementation routing, covers ad conversion attribution changes in high-risk review, and checks explicit reasoning effort against recorded native dispatch parameters.
