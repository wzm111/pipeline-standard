# v3.14.7 Python 3.14 审计权限修复

工作区扫描改用显式文件状态读取，保留 Python 3.14 下的目录权限错误。不可读项目会显示 permission_denied 并标为部分覆盖。中英文 README 已同步稳定版链接与固定版本安装说明。

本地通过 29 项审计测试、779 项 Python 回归测试和 Codex 冒烟测试。权限错误通过本地隔离目录复现，测试清理时恢复目录权限。

Workspace audit scans now preserve permission errors on Python 3.14 and report partial coverage for unreadable projects. Both READMEs point to v3.14.7.
