- `94696f6`：同进程终验收口前先核验停止证据、角色、检查、任务及人工等待等前提，最终仍重新核验完整证据和真实环境。

- `d8390d0`：显式绑定主流程的角色在宿主实际接受后同步阶段；所选角色全部返回后进入交接，保护后台角色、人工等待和新的主状态。

## 累积改进

管理型运行增加规则版本确认与机器验收门禁，拒绝手写 PASS、失效证据和后续失败被旧成功覆盖。保留旧运行兼容，但不将旧记录视为已采用新规则。

支持有效检查与交付证据承接、关键边界快检、原子宿主观察、浏览器夹具交接、预览目录保护，以及发布范围、有界恢复和人工等待的真实记录。原有权限、验收上限、来源链及环境校验保持不变。

## 验证与使用边界

实现提交 `b586706` 已通过 40 个 Python 测试文件共 486 项测试、Codex 安装冒烟、Shell 语法、差异检查和 skill 校验，并完成独立验收。本次仅新增发布说明，不重复运行相同实现的本地全量回归；远端 CI 与实际发布标签另行核验。

日志和进度只表示已采集的事实，不证明当前宿主健康、业务验收或真实提速。未知模型、token、排队和历史时间不估算，不承诺固定节省比例。进度脚本不会自行发送聊天消息，仍需执行会话采用。

已安装的 Claude/Codex skill 链接可直接使用更新后的检出内容。已有会话需重读最新版 `SKILL.md` 及本次所需引用，保留当前任务和有效证据；无需重做已完成检查。本版本不改写用户的模型配置或业务项目配置。
