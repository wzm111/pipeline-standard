# v3.14.3 本地审计覆盖与实时扫描

- 跨项目扫描分别统计可用的实时摘要、缺少当前磁盘快照的实时摘要，以及无法生成的实时摘要。
- 显式指定的项目缺少本地运行状态目录时，扫描标为部分覆盖。目录存在但没有运行记录时，单独显示为零条。
- 单项目审计脚本的 `scan --live` 正确生成实时摘要，保持只读。

Cross-project scans distinguish live summary availability from saved snapshot coverage and report missing local state directories separately from empty ones. The standalone audit scanner now honors `scan --live`.
