# v3.12.0：仅本地的运行报告预览

本版本增加本地诊断报告预览，沿用已有运行记录，不增加报告上传、GitHub提交、接收端、令牌或自动上报配置。

## 使用方式

在项目会话中说“预览本项目的运行报告”，或从本地终端调用 skill 的 `pipeline_cli.py preview --project <项目目录>`。默认显示中文文本，可显式选择 `--format json`。

- 未指定run时，优先预览当前活动运行；没有活动运行时，使用已有有界扫描选择最近记录。活动归属不明或最新记录损坏时拒绝，不退回旧成功记录。
- 默认读取已有快照，明确标注缺失和过期。`--live`只在内存中计算已登记元数据，不补写历史或保存报告副本。
- 保留未知、部分采集和截断提示。登记成功、规则确认及证据覆盖记录不代替业务验收、宿主健康或证据复用核验。

## 数据边界

预览只输出固定枚举、数字、布尔值及合法时间，排除run ID、内部指纹、项目目标和路径、命令、日志正文及凭据。预览不扫描项目内容或原始业务日志，不启动子进程、网络请求、浏览器或上传。

可在终端本地查看。若由聊天智能体调用并展示，预览文本可能进入当前对话，处理方式取决于宿主；诊断模块不联网不等于整个宿主离线。不会在运行后自动把预览贴到聊天或外部位置。

原始状态、证据及日志继续保存在项目本地并遵循原权限和脱敏规则；清理`tmp/pipeline/`会删除本地记录。安全摘要不是整个运行目录均可公开的承诺。
