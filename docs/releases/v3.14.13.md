# v3.14.13 发布预检与证据复用

- 项目可在 `pipeline.release.json` 中声明只读 `readiness_probe`。正式预检先核对生产驱动绑定和目标权限，缺项按原因码返回。
- 探针与正式预检按同次执行和发布目标绑定。切流启动前复核最新的预检与兼容性证据，较新的失败会拦截切流。
- 重试同一发布计划时，自动复用仍有效的正式运行器兼容性检查。生产驱动和目标权限每次正式预检实查。

A project can opt in to a read-only readiness probe for driver binding and target permissions. Activation revalidates the bound preflight and runner evidence. Valid runner compatibility checks can be reused within the same release plan.
