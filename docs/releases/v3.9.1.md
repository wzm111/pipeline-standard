# v3.9.1：安装默认模型配置与升级保护

修复项目没有模型配置时缺少明确本机默认的问题。安装器现在会准备本机默认文件，项目只需按需覆盖，用户无需手填配置。

## 更新内容

- 新增skill默认模板defaults/models.json，Codex和Claude各包含五角色；初始均继承当前模型，不写死具体型号或推理强度。
- 安装时原子初始化 ~/.config/pipeline-standard/models.json；重装和升级保留已有配置，不覆盖用户选择。损坏、未知版本或符号链接配置保留原状并报错。
- 解析优先级为：本次指定 > 项目 > 本机默认 > skill模板（旧安装兜底）> 运行时默认。项目仅覆盖其配置的角色，其余继续使用本机默认。
- 解析器基于skill真实路径定位模板，支持安装软链接；即使项目无配置也解析角色来源，不向项目写入多余文件。
- 创建角色前仍校验当前宿主能力。旧型号不可用时提示重选、继承当前或暂不执行；经确认后更新对应配置，不静默换模。
- 更新对话规则、安装提示和使用说明，区分配置偏好、请求参数与实际模型反馈。

## 验证

70项本地行为测试、安装冒烟、Shell语法、差异检查和skill校验通过。新增覆盖首次安装有默认、升级保留选择、项目局部覆盖、临时覆盖、损坏配置保护以及安装软链接解析。

以上不替代真实模型调用验收；继承模式不表示不同角色已经使用不同型号。本版本没有新增速度或token节省声明。

## 使用

更新仓库后由智能体运行安装/同步即可初始化本机文件；已有文件会保留。旧安装未运行安装器时，也可从skill模板读取继承默认。新开会话加载最新规则。

说“配置模型”修改当前项目，说“改本机默认”修改所有未被项目覆盖的角色；不需要编辑文件。已运行角色不会因文件更新自动切换。
