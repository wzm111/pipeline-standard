# v3.14.21 精简实施与验证

- 开工时明确影响实现的假设，新增抽象或配置前核对现有实现。现版已达标可用证据直接收口，实施中可按新证据缩减剩余工作。
- 审查从实际改动反查需求。稳定复现的普通缺陷沿用同一条件做改前、改后验证，兼容性验收同时检查新行为和要保留的旧行为。
- QA 打回后记录新增观察、修改位置和复测方法。快发的隔离回归核对同一产物、构建和切流次数，以及切流后的回读。
- 用一对相近场景验收 Skill 的实际路由和下一步，分别记录文档走查、解析结果和真实宿主采用。

Pipeline can now use narrower implementation and verification plans, tie diffs back to requirements, carry new evidence into each QA retry, and verify release side effects. Paired trial scenarios make skill adoption observable in native sessions.
